```text

Caption review jujur untuk produk: [nama produk].
Poin dari saya:
- plus: [poin plus]
- minus: [poin minus]
- cocok untuk: [target user]
Hashtag: affiliate, review, fyp, rekomendasi
Link: [link affiliate]
Bahasa: id
Lalu cek status publish-nya.
```

## Tips pakai harian

| Hari | Prompt yang cocok |
|------|-------------------|
| Senin | Review jujur (#1) |
| Selasa | Unboxing (#2) |
| Rabu | Comparison (#3) |
| Kamis | Soft-sell (#4) |
| Jumat | Before-After (#5) |
| Sabtu | Tier list (#6) / Myth vs Fact (#7) |
| Minggu | Daily essential (#8) atau FAQ (#9) |

## Checklist cepat sebelum kirim prompt

- [ ] Path video sudah benar  
- [ ] Link affiliate sudah diisi  
- [ ] Poin caption hanya dari fakta kamu  
- [ ] Platform sesuai akun yang terhubung di AiToEarn  
- [ ] Ada instruksi “cek status” di akhir  

Kalau mau, next step saya bisa buatkan **versi lebih spesifik niche** (skincare, gadget, makanan, atau Shopee/TikTok Shop).
